Installation guide
  1. Extract the complete package.
  2. Open Windows PowerShell as Administrator.
  3. Run .\Install-Managed-Proxy.ps1.
  4. Verify with .\payload\Proxy-Control-Endpoint.ps1 -Mode Status.

The optional desktop GUI installer can be built using .\Build-For-This-Gateway.ps1. Standard users can view status; changing or removing the policy requires administrator privileges.

How fallback works

DIRECT fallback applies when the proxy cannot be reached. Client timeout and PAC caching affect recovery time. Applications with their own proxy settings need separate configuration. Router rules must permit direct access for fallback and bypasses to work.
