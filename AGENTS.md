# Project instructions

Use the Cloudflare `security-audit` skill for security questions, security-sensitive changes, and security reviews in this project. Read the installed `security-audit/SKILL.md` before applying it. Upstream: https://github.com/cloudflare/security-audit-skill

Apply guidance mode for focused work. Use the complete audit workflow only when its scope is explicitly authorized, following the skill's requirements for independent verification, isolated execution, evidence, and reporting. Do not describe functional tests or source inspection as a completed security audit.

Preserve a simple administration workflow: assign applications and domains through access profiles with their VLANs; keep proxy bypass separate and clearly labeled. Put advanced controls behind progressive disclosure and maintain readable contrast.
