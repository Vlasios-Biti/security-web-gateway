Recovery updates and channel tests never mention people. Slack permissions and individual notification preferences control whether a mention produces a push notification. Changing the channel label does not change the destination; replace the webhook to change channels.

Credentials are stored in a protected configuration file on this VM. Existing passwords and webhook URLs are never returned in the form and are excluded from policy-state exports.

SNMP monitoring

SNMPv2c for a private management network. Community strings are not encrypted on the network. Polling is read-only and independent of the notification master switch.

Configure SNMP

Trap delivery records local UDP submission, not confirmation by the receiver. Polling: base.1.0 health (0 unknown, 1 healthy, 2 warning, 3 critical); .2.0 active incidents; .3.0 CPU ×100; .4.0 memory ×100; .5.0 disk ×100; .6.0 stale sampler; .7.0 proxy listener; .8.0 version.

Alert thresholds & repeat control

The monitor runs approximately once per minute after the previous run finishes. Failed deliveries retry with backoff independently for each channel. This VM cannot report its own total power or network loss; use an external uptime check for that.
